# ENC28J60

The byte-SPI overlay streams RCR/WCR/BFS/BFC register operands and buffer operations. Register names follow all four banks in [Microchip DS39662E](https://ww1.microchip.com/downloads/en/DeviceDoc/39662e.pdf), table 3-1, including the common EIE/EIR/ESTAT/ECON2/ECON1 registers.

Capture-start bank state is unknown. A soft reset establishes bank zero; a complete ECON1 read/write establishes both bank bits; bit-set/clear operations establish only the bits they affect. Names remain unknown until both bits are known. A gap or aborted transfer forgets inferred bank state.

`dummy_mode=auto` uses the observed bank and register class to skip the MAC/MII read dummy byte. An ambiguous banked read is drained with `unknown-bank`, rather than interpreting a possible dummy byte as data. Explicit `mac-mii` and `ethernet` modes allow a known capture profile to choose alignment without inventing register names. Common-register reads never have a dummy byte. `register` events identify the bank/name at the command; `bank` events report observed bits and their known mask.

Register operands and common control/status bits are decoded. Ethernet packet parsing, PHY-management transactions and a complete register-value state machine remain outside this profile. Bounded scalar state is retained; complete prior fields keep their provenance after an aborted transaction.

The regression exercises unknown-start rejection, reset, bank-zero ERDPTL, bit-set selection of bank-two MACON1 with a dummy byte, bit-clear return to bank zero without a dummy byte, and bank-three MAADR5. Compiled/interpreted and scheduling checks are required at the expanded checkpoint.
