# x2444m

The authoritative implementation is `dsl/decoders/x2444m.ts`. Its schema, configuration defaults and localized labels are generated from that source.

Start bit, 4-bit address, named WADS/STO/SLEEP/WRITE/WREN/RCL/READ commands and 16-bit data.

The remaining scope is: Nonvolatile operation timing, dummy-read timing verification, variants.

Reference: Original Xicor X2444 data sheet in [1985 data book](https://bitsavers.org/components/xicor/_dataBooks/).

Verification: Independent WRITE/READ instruction, address and data vectors pass with generated/interpreted event and provenance comparisons. Test checkpoints are recorded in the [SPI coverage ledger](spi-porting-coverage.md).

Events carry sample provenance. Gaps discard incomplete fields; complete previously emitted fields remain observations. Buffers are bounded and no whole transaction is retained. See the coverage ledger for input word widths, capture wiring and shared limitations.
