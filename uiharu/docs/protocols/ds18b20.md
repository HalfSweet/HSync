# DS18B20

The DS18B20 decoder (`Ds18b20`, in `crates/uiharu-protocols/src/ds18b20/`) reads [`onewire.events`](onewire.md) and reports the function commands sent to a DS18B20 digital thermometer and what they carry on `ds18b20.events`. It is implemented from the DS18B20 datasheet (Maxim Integrated / Analog Devices, _DS18B20 Programmable Resolution 1-Wire Digital Thermometer_).

The decoder has no configuration and requires nothing of `onewire.events` beyond its schema; any other stream, such as the SPI decoder's `spi.events` or the 1-Wire link layer's `onewire.link`, is refused when the graph is connected. Its output declares `family = 40` (`0x28`).

## Events

Every event carries `tx`, the 1-Wire transaction it rides on.

| Kind                 | Fields                                                                                                       | Meaning                                                                                                    |
| -------------------- | ------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| `command`            | `code: u8`                                                                                                   | a function command the decoder knows; an `end` follows                                                     |
| `scratchpad`         | `bytes: [u8; 9]`, `crc_ok: bool`, `temperature_raw: i16`, `th: i8`, `tl: i8`, `config: u8`, `resolution: u8` | the nine bytes Read Scratchpad read, and the registers they hold                                           |
| `partial-scratchpad` | `bytes: [u8]`, `temperature_raw: i16 \| null`                                                                | the 1 to 8 bytes of a Read Scratchpad that ended early; the temperature when both its bytes were read      |
| `write-scratchpad`   | `th: i8`, `tl: i8`, `config: u8`                                                                             | the three bytes Write Scratchpad wrote                                                                     |
| `power-supply`       | `parasite: bool`                                                                                             | the read slot after Read Power Supply: pulled low by a parasite-powered device                             |
| `unknown-command`    | `code: u8`                                                                                                   | a function command the decoder does not know; the rest of its transaction is skipped, and no `end` follows |
| `end`                | `reason`: `complete`, `incomplete` or `aborted`                                                              | the command ended                                                                                          |

`temperature_raw` is the temperature register as it is: two's complement in sixteenths of a degree Celsius (divide by 16 for °C; at 9 to 11 bits the lowest bits are undefined). `th` and `tl` are the alarm registers, or user bytes, as signed bytes. `resolution` is what bits 5 and 6 (R0, R1) of `config` set: 9 to 12 bits. `crc_ok` says whether the ninth byte is the CRC-8 of the first eight.

| Event                           | Span                                                          | Settled                                                            |
| ------------------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------ |
| `command`, `unknown-command`    | the transaction from its reset through the command byte       | the command's last slot                                            |
| `scratchpad`                    | its nine bytes                                                | the last slot                                                      |
| `partial-scratchpad`            | the bytes read                                                | where the transaction ended                                        |
| `write-scratchpad`              | its three bytes                                               | the last slot                                                      |
| `power-supply`                  | the byte or bits holding the slot                             | as the 1-Wire stream settled them                                  |
| `end` (`complete`)              | the 1-Wire end, and what was read after the command's data    | the reset that ended the transaction                               |
| `end` (`incomplete`, `aborted`) | what was read but not reported, through the transaction's end | the reset, the bad slot, the gap's start or the end of the samples |

## Rules

- A transaction addresses the device when its ROM command is Skip ROM, Match ROM or Read ROM with the family code `0x28`, or one of their overdrive variants (Overdrive Skip ROM, Overdrive Match ROM with `0x28`). The datasheet lists neither overdrive variant: the decoder reports what the master sent, and a DS18B20 that ignores them leaves its read slots high (a scratchpad of `FF` bytes with a failing CRC). A transaction addressed to another family, a search (after which the datasheet asks for a reset) and an unknown ROM command are ignored.
- The first byte after the ROM level is the function command: Convert T (`0x44`), Write Scratchpad (`0x4E`), Read Scratchpad (`0xBE`), Copy Scratchpad (`0x48`), Recall E² (`0xB8`) or Read Power Supply (`0xB4`). Any other code is an `unknown-command`.
- Read Scratchpad: the nine bytes that follow are the scratchpad — temperature LSB and MSB, TH, TL, configuration, three reserved bytes and the CRC. It is reported as soon as its ninth byte is read; bytes read after it are skipped. When the transaction ends before the ninth byte, the bytes read are reported as a `partial-scratchpad`, then the `end`.
- Write Scratchpad: the three bytes that follow are TH, TL and the configuration.
- Read Power Supply: the read slot after the command — bit 0 of the next byte, or the first of the bits the transaction ended with — is 0 when a device is parasite-powered.
- Convert T, Copy Scratchpad and Recall E²: the command alone. The read slots a master may poll afterwards (the device's busy bits) are skipped.
- A command ends `complete` at the transaction's normal end, the next reset, once what it carries was whole; `incomplete` when the reset came first; `aborted` when a bad slot, a gap or the end of the samples cut the transaction off. After a gap, transactions resume at the next reset.

## Limits

- Only the DS18B20 (family `0x28`); the DS18S20 (`0x10`), DS1822 (`0x22`) and DS1825 (`0x3B`), whose scratchpads differ, are not decoded.
- The busy bits after Convert T, Copy Scratchpad and Recall E² are not reported.
- Temperatures are not converted to degrees, and alarm conditions are not evaluated.
