# ad5626

The authoritative implementation is `dsl/decoders/ad5626.ts`. Its schema, configuration defaults and localized labels are generated from that source.

Exactly 12 MOSI clocks, DAC code and nominal internal 1mV/LSB microvolts.

The remaining scope is: External analog measurement and DAC load timing.

Reference: [AD5626](https://www.analog.com/media/en/technical-documentation/data-sheets/ad5626.pdf).

Verification: Independent ABC DAC code and voltage. Test execution is recorded in the [SPI coverage ledger](spi-porting-coverage.md); authored vectors are not a passing-test claim.

Events carry sample provenance. Gaps discard incomplete fields; complete previously emitted fields remain observations. Buffers are bounded and no whole transaction is retained. See the coverage ledger for input word widths, capture wiring and shared limitations.
