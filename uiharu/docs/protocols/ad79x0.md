# ad79x0

The authoritative implementation is `dsl/decoders/ad79x0.ts`. Its schema, configuration defaults and localized labels are generated from that source.

AD7910/7920 16-clock conversion, padding validity, 10/12-bit selection, explicit integer reference µV, early-CS power-down request.

The remaining scope is: Other AD79xx layouts and inferred device power state.

Reference: [AD7910/7920](https://www.analog.com/media/en/technical-documentation/data-sheets/ad7910_7920.pdf).

Verification: Midscale voltage, invalid padding, short power-down request. Test execution is recorded in the [SPI coverage ledger](spi-porting-coverage.md); authored vectors are not a passing-test claim.

Events carry sample provenance. Gaps discard incomplete fields; complete previously emitted fields remain observations. Buffers are bounded and no whole transaction is retained. See the coverage ledger for input word widths, capture wiring and shared limitations.
