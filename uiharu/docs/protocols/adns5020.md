# adns5020

The authoritative implementation is `dsl/decoders/adns5020.ts`. Its schema, configuration defaults and localized labels are generated from that source.

Shared SDIO or split capture, named registers, motion burst, motion flags and raw delta/shutter/surface fields.

The remaining scope is: Signed delta conversion and complete sensor configuration semantics.

Reference: [Avago ADNS5020](https://datasheet.octopart.com/ADNS-5020-EN-Avago-datasheet-10313908.pdf).

Verification: Named register and motion subfield vectors pass with generated/interpreted event and provenance comparisons. Test checkpoints are recorded in the [SPI coverage ledger](spi-porting-coverage.md).

Events carry sample provenance. Gaps discard incomplete fields; complete previously emitted fields remain observations. Buffers are bounded and no whole transaction is retained. See the coverage ledger for input word widths, capture wiring and shared limitations.
