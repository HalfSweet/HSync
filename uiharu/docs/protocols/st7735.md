# st7735

The authoritative implementation is `dsl/decoders/st7735.ts`. Its schema, configuration defaults and localized labels are generated from that source.

Logic CS/CLK/D/D-C, four-wire bytes, raw parameters, CASET/RASET and observed COLMOD RGB565/RGB666 pixels.

The remaining scope is: Readback, parallel/three-wire modes, framebuffer and reset/tearing pins.

Reference: [Sitronix ST7735S original](https://e2e.ti.com/cfs-file/__key/communityserver-discussions-components-files/908/ST7735S_5F00_v1.3.pdf).

Verification: Observed COLMOD, address-window and RGB565 pixel vectors pass with generated/interpreted event and provenance comparisons. Test checkpoints are recorded in the [SPI coverage ledger](spi-porting-coverage.md).

Events carry sample provenance. Gaps discard incomplete fields; complete previously emitted fields remain observations. Buffers are bounded and no whole transaction is retained. See the coverage ledger for input word widths, capture wiring and shared limitations.
