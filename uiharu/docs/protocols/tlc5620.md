# TLC5620

`tlc5620` consumes logic CLK/DATA and optional LOAD/LDAC. It shifts on falling CLK while LOAD is high; LOAD falling latches the last eleven bits, including transfers padded to sixteen clocks. Each DAC has its own configured reference in integer microvolts. Ideal output is reference × code × (1 + range) / 256.

A low LDAC updates the selected output immediately. A later LDAC falling edge emits an update-all mask and voltage updates only for DACs whose input registers have been observed. Unknown power-on values are never fabricated. With LDAC absent, the explicit low assumption controls immediate updates. With LOAD absent, `word_aligned` must explicitly permit eleven-clock framing; decoded words do not claim a hardware latch or output update.

The implementation retains bounded scalar state. Gaps forget partial words and all inferred DAC input values. Analog settling and pulse-width compliance are outside this digital profile.

Reference: [Texas Instruments SLAS081E](https://www.ti.com/lit/ds/symlink/tlc5620.pdf), figures 1–4 and table 2. Four compiled/interpreted tests pass, covering independent references, deferred simultaneous updates, sixteen-clock padding, absent control lines, partial words, gaps and scheduling invariance.

Configuration without LOAD is rejected unless `word_aligned` explicitly asserts an aligned capture start. UI layout verification passed; LOAD/LDAC, reference and alignment labels have been polished in both locales.
