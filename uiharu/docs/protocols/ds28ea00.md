# DS28EA00

`ds28ea00` consumes canonical native `onewire.events@1`. Configuration is empty.
Skip ROM selects this device profile; an observed ROM requires family 42h and a
valid CRC. Conditional Read ROM (0Fh) is recognized from the network's generic
bytes, including its eight-byte ROM and subsequent Chain function in the same
transaction. The lower bus remains generic.

The original TypeScript consumer names all nine functions and streams scratchpad
bytes. A complete nine-byte read reports CRC8 and temperature in integer
microdegrees, with a separate sign and observed 9–12-bit resolution. Undefined
low temperature bits are masked using the observed configuration. It decodes
PIO input/output latch bits and complemented nibbles, write/complement/AAh/readback
cycles, Chain OFF/ON/DONE control/complement/confirmation, and byte or trailing-bit
conversion/recall/power status. Write Scratchpad bytes remain streamed raw data.

PIO electrical behavior, chain wiring order, programming and conversion duration
are not inferred. Missing samples clear bounded state; truncated fields never
produce an invented complete reading. CRC-invalid readings retain their validity
flag. ROM identifiers use the native hexadecimal-u64 wire representation.

Wire facts come from the manufacturer's [DS28EA00 revision 2 specification](https://www.analog.com/media/en/technical-documentation/data-sheets/DS28EA00.pdf),
control functions and sequence-discovery examples. The pinned DSView command
inventory was a scope reference only; no GPL implementation was copied or
adapted. Native/generated/interpreted vectors, negative temperature, PIO checks,
chain/conditional ROM, status bits, gaps and scheduling are in
`uiharu-interp/tests/p4_devices.rs`.
