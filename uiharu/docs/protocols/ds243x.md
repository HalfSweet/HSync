# DS2432 and DS2433

`ds243x` consumes canonical `onewire.events@1`, downstream of `onewire-link` and
`onewire`. `model` defaults to `ds2432` and also accepts `ds2433`. A valid observed
ROM overrides it using family 33h/23h. With Skip ROM there is no observable family,
so the configured fallback applies. Invalid ROM CRC or another family suppresses
function-byte interpretation until reset.

The original TypeScript consumer streams command, little-endian target address,
scratchpad/memory/authorization/MAC bytes, E/S, CRC16 and completion states. DS2432
scratchpad transfers use eight bytes, including write-address alignment behavior;
DS2433 uses the remaining bytes in its 32-byte scratchpad. Write CRC covers the
actual address sent. DS2432 read scratchpad has an inverted CRC16; DS2433 read
scratchpad does **not**, matching its specification. Partial reads/writes remain
visible without fabricating missing bytes.

DS2432 additionally decodes Load First Secret and Compute Next Secret transport,
Copy Scratchpad's 20-byte authorization MAC, and Read Authenticated Page's page
remainder, FFh padding, first CRC, 20-byte MAC, second CRC and completion stream.
MACs are streamed, never cryptographically authenticated: the secret and hardware
execution are not observable. No retained EEPROM image or programming-time claim
is made. State is scalar and bounded; gaps discard alignment until the next reset.

Sources are the manufacturer-authored [full preliminary DS2432 specification](https://media.digikey.com/pdf/Data%20Sheets/Dallas%20Semiconductor%20PDFs/DS2432.pdf)
(memory commands and authentication transport), the current
[abridged DS2432 specification](https://www.analog.com/media/en/technical-documentation/data-sheets/DS2432.pdf),
and [DS2433 specification](https://www.analog.com/media/en/technical-documentation/data-sheets/DS2433.pdf).
The pinned DSView annotation inventory supplied scope only; no GPL implementation
was copied or adapted. Independent vectors in `uiharu-interp/tests/p4_devices.rs`
cover both families, offsets, both CRC stages, MAC lengths and scheduling/gaps.
