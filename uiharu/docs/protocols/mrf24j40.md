# mrf24j40

The authoritative implementation is `dsl/decoders/mrf24j40.ts`. Its schema, configuration defaults and localized labels are generated from that source.

Short/long register addresses, named controls, TX/RX FIFO length/payload streaming, retry count and TX/CCA failures.

The remaining scope is: Complete MAC frame parsing, frame security, RX metadata and unexpected FIFO-address continuity validation.

Reference: [Microchip MRF24J40](https://ww1.microchip.com/downloads/en/devicedoc/ds-39776b.pdf).

Verification: FIFO frame and retry/TX/CCA failure vectors pass with generated/interpreted event and provenance comparisons. Test checkpoints are recorded in the [SPI coverage ledger](spi-porting-coverage.md).

Events carry sample provenance. Gaps discard incomplete fields; complete previously emitted fields remain observations. Buffers are bounded and no whole transaction is retained. See the coverage ledger for input word widths, capture wiring and shared limitations.
