# sda2506

The authoritative implementation is `dsl/decoders/sda2506.ts`. Its schema, configuration defaults and localized labels are generated from that source.

Logic input CLK/D/CE; LSB-first 8/16-bit header, CE-low read, erase/write requests and reused latch.

The remaining scope is: TP2 total erase, programming pulse-duration checks, physical write verification.

Reference: [Siemens original 1994 datasheet](https://dtsheet.com/doc/196319/infineon-sda2506-5).

Verification: Independent read/write/reuse vectors and gap/invariance. Test execution is recorded in the [SPI coverage ledger](spi-porting-coverage.md); authored vectors are not a passing-test claim.

Events carry sample provenance. Gaps discard incomplete fields; complete previously emitted fields remain observations. Buffers are bounded and no whole transaction is retained. See the coverage ledger for input word widths, capture wiring and shared limitations.
