# st7789

The authoritative implementation is `dsl/decoders/st7789.ts`. Its schema, configuration defaults and localized labels are generated from that source.

Same four-wire write profile with ST7789 command framing.

The remaining scope is: Readback, parallel modes and device-specific extended command interpretation. In the pinned reference, WRX is the serial command/data signal and DCX is the clock; DSView import maps these to DC and CLK respectively.

Reference: [Sitronix ST7789](https://www.waveshare.com/w/upload/a/ae/ST7789_Datasheet.pdf).

Verification: Four-wire command/parameter vectors pass with generated/interpreted event and provenance comparisons. Test checkpoints are recorded in the [SPI coverage ledger](spi-porting-coverage.md).

Events carry sample provenance. Gaps discard incomplete fields; complete previously emitted fields remain observations. Buffers are bounded and no whole transaction is retained. See the coverage ledger for input word widths, capture wiring and shared limitations.
