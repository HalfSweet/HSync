# nrf905

The authoritative implementation is `dsl/decoders/nrf905.ts`. Its schema, configuration defaults and localized labels are generated from that source.

Config read/write, payload/address operations, channel/band/power/retransmit/address widths/payload sizes/CRC/crystal/output-clock fields.

The remaining scope is: Radio timing and over-air interpretation.

Reference: [Nordic nRF905 original v1.1](https://cdn.sparkfun.com/assets/5/8/c/f/8/nRF905_rev1_1.pdf).

Verification: Named operation and register subfield vectors pass with generated/interpreted event and provenance comparisons. Test checkpoints are recorded in the [SPI coverage ledger](spi-porting-coverage.md).

Events carry sample provenance. Gaps discard incomplete fields; complete previously emitted fields remain observations. Buffers are bounded and no whole transaction is retained. See the coverage ledger for input word widths, capture wiring and shared limitations.
