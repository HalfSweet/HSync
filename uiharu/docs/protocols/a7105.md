# A7105

The original AMICCOM A7105 v1.4 profile names all51 registers00h–32h and decodes masked sleep/idle/standby/PLL/RX/TX/FIFO-reset strobes. Register operands, FIFO/ID bytes and selected mode, calibration, FIFO, TX, whitening, FEC/CRC and code controls stream without retaining a transaction. Only FIFO and ID have repeated bytes at one register; ordinary control accesses are one byte rather than invented auto-increment reads.

PDV bits in TX II are documented reserved, so they are reported as reserved codes rather than transmit power. TX test register28h exposes actual TX current, PA current and buffer codes. No unobserved analog power or calibration result is inferred. Full analog/test bitfields and over-air packet reconstruction remain outside the profile.

Reference: [AMICCOM original January2011 v1.4 specification](https://www.mantech.co.za/Datasheets/Products/a7105-amiccom.pdf), sections9.2/10. Independent vectors name all51 registers, distinguish mode read flags, verify strobes with ignored low bits and check PA controls; the shared test helper compares compiled and interpreted provenance and scheduling.
