# DS2408

`ds2408` consumes the canonical native `onewire.events@1` stream. Connect logic
through `onewire-link` and `onewire` first. Configuration is empty. Skip ROM is an
explicit DS2408 profile; an observed ROM must have family 29h and a valid CRC.

The original TypeScript implementation names all six control commands. It streams
F0h target-address/register bytes and verifies their inverted CRC16, handles F5h
32-sample groups with the command included only in the first group's CRC, and
reports each 5Ah output/complement/AAh-confirmation/readback cycle. CCh targets
8Bh–8Dh and C3h repeated confirmations are decoded. The special disable-test
sequence is ROM command 96h, eight ROM bytes and 3Ch, rather than an ordinary
function command. ROM IDs retain hexadecimal-u64 JSON serialization.

Data, inverse checks, CRC results and confirmations are separate events; a failed
check never becomes an inferred pin transition. Incomplete fields and missing
samples discard bounded state and recover at the next reset. No transaction,
register image, electrical timing or analog output is buffered or inferred.

Wire facts are from the manufacturer's [DS2408 revision 3 specification](https://www.analog.com/media/en/technical-documentation/data-sheets/DS2408.pdf),
control-function commands and disable-test application note. The pinned DSView
annotation inventory was consulted only for scope; no GPL implementation was
copied or adapted. `uiharu-interp/tests/p4_devices.rs` supplies independent native
bus/generated/interpreted traces, CRC groups, failed complements, register
addresses, truncation, gaps and scheduling/backpressure checks.
