# LM75 and compatible temperature words

`lm75` is a TypeScript DSL decoder over `i2c.events`, implemented independently
from the [manufacturer datasheet](https://www.ti.com/lit/ds/symlink/lm75b.pdf) (SNIS153D, §§7.5.8–7.6). The configurable 9–12-bit compatible word profile additionally follows the [TI TMP175/TMP75 data sheet](https://www.ti.com/lit/ds/symlink/tmp75.pdf), resolution table. Resolution is a user selection; observing TMP75 configuration writes does not automatically change this profile. Its source is
[`lm75.ts`](../../dsl/decoders/lm75.ts); generated Rust and IR are never edited by hand.

## Configuration and contract

`address` is a seven-bit target address, default `0x48`. Ten-bit addresses and
other targets are ignored. Input is `i2c.events` version 1; output is
`lm75.events` version 1 with output property `address`.

| Kind      | Meaning                                                                                 |
| --------- | --------------------------------------------------------------------------------------- |
| `begin`   | One addressed segment: `op`, lower `tx`, `read` direction, address `ack`                |
| `pointer` | Attempted register/command pointer and its ACK; absent on pointerless devices           |
| `byte`    | Immediate raw byte, optional known `register`, `read`, `ack`                            |
| `field`   | Decoded numeric field: `register`, enum `field`, magnitude `value`, `negative`, `valid` |
| `end`     | Segment result: complete, incomplete, aborted or nack                                   |

A read-ending NACK is normal and its final byte is retained. An unacknowledged
write does not change interpreted device state and invalidates the pointer.
An unknown pointer stays unknown; raw bytes are retained. START/repeated START
closes a segment; a STOP closes the last segment. Initial partial I²C frames are
drained. Gaps and truncation abort open segments and clear pointer knowledge.

## Device rules

The persistent pointer does not auto-increment. Register 1 is one configuration byte. Registers 0, 2 and 3 take MSB then LSB and decode configured 9–12-bit two’s-complement temperature, hysteresis and overtemperature limits (default 9 bits at 0.5 °C resolution). Field `value` is an unsigned magnitude in micro°C and `negative` carries the sign: `ff 80` gives 500000 with negative true; `19 00` gives 25000000 with negative false. The configured low unused bits are excluded. `resolution` is 9–12 (default 9); 12-bit values retain exact 62500 micro°C steps. An unfinished word emits raw bytes and ends `incomplete`; it never becomes a fabricated temperature.

## Streaming and limits

Every byte is reported before later data is read. There is no transaction-sized
buffer: state is a pointer, counters, constant-size mode flags, and at most one
unfinished byte with its provenance. Multi-byte field spans cover only their
observed bytes and settle on their final byte; a held first byte holds progress
back to its start. Byte/field events preserve consumed I²C event provenance;
segment ends use the item that decided them. Bounded queues and awaited reads/writes
provide backpressure and cancellation.

TI LM75B/C use 9 bits. Other configured widths interpret the same left-justified wire format used by compatible sensors, without claiming identical configuration-register semantics or automatic resolution negotiation. No thermostat-output inference.
